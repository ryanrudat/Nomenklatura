# Session 027 - Economics & Politics Systems Overhaul

**Date:** 2026-04-14

## Summary

Massive overhaul of the economics and politics systems. Fixed a critical bug where ALL economic policy effects were silently failing due to 15 policy slot ID mismatches. Replaced the Ladder navigation tab with a full Economy (Gosplan) tab. Added deep economics systems: sector specialization (32 focus options), trade negotiation with tariffs/embargoes, budget allocation, and foreign loans. Wired economy-politics feedback loop and dynamic world economy events. Also fixed General Secretary display, rebellion spam, redacted content, track affinity wiring, and Security bureau character selection.

## Batch 1: Politics & Economy Engine Fixes (5 units)

### 1. Track Affinity Wiring
- `game.addTrackAffinity()` now called from directive execution (+3 per directive, mapped by bureau track) and personal action execution (+2 per action, mapped by category)

### 2. Security Bureau Character Selection
- BPS directives (Open Investigation, Request Surveillance, Issue Detention) now show character selection overlay instead of auto-picking targets
- Added `characterSelectionOverlay`, `characterTargetRow`, `securityTargetStatusIndicator`, `finalizeSecurityDirective` to DirectivePhaseView
- `BureauOperationsService.executeTask()` accepts optional `targetCharacter`

### 3. Economic Engine Overhaul (CRITICAL BUG FIX)
- Fixed ALL 15 policy slot ID mismatches across 4 files:
  - EconomyService: 11 mismatches
  - PolicyService: 3 mismatches
  - Game: 1 mismatch
- Fixed 2 option ID mismatches in PoliticalAIService
- ALL economic policy effects were silently failing because IDs didn't match DefaultPolicySlots
- Rebalanced: stability penalty -10 to -5, industrial penalty -5 to -3, growth floor at -3, GDP momentum +1 when growing
- Wired Reformist faction economic bonus

### 4. Economy-Politics Integration
- Moved `processEconomicSystem()` before `processPoliticalAI()` in turn order
- Added `applyEconomicPoliticalFeedback()`:
  - Low treasury: elite loyalty drop
  - Food shortage: popular support drop
  - Unemployment: stability drop
  - Inflation: stability drop
  - Strong economy: support boost

### 5. Dynamic World Economy
- Added `economicCompatibility()` to ForeignCountry
- Enhanced `calculateTradeBalance()` with compatibility-weighted bonuses
- Added `isSocialist`/`isMarket` helpers to EconomicSystemType
- Added `generateDynamicEconomicEvents()` with trade proposals (5%), sanctions (8%), and foreign reform (7%) events

## Deep Economics Systems (3,361 lines)

### 1. Sector Specialization (957 lines)
- SectorFocus model with 32 production focus options (4 per sector)
- Examples: Heavy Industry: tanks/tractors/steel/machinery; Agriculture: collectives/private plots/export crops/mixed
- Each has trade-offs in stats, morale, efficiency, treasury
- SectorDetailView shows performance bars, dependencies, focus option cards with ACTIVATE buttons
- Focus effects wired into `EconomyService.processSectorPerformance()`

### 2. Trade Negotiation (1,000 lines)
- TradeProposalSheet: interactive deal builder with type selection, favorability slider, duration, projected effects
- TariffLevel enum (none/low/standard/high/prohibitive) with volume/revenue multipliers
- Per-country embargo system
- Tariffs/embargoes wired into `calculateTradeBalance()`
- Added `tariffLevel` and `embargoedCountries` to Game

### 3. Budget & Loans (1,404 lines)
- Per-sector budget allocation (8 sectors, must sum to 100%)
- ForeignLoan struct with principal, interest rate, duration, per-turn payments
- Loan sources: socialist bloc (2-3%), Western (4-5%), international (5-8%)
- Max 3 concurrent loans
- LoanProposalSheet for loan applications
- Loan payments processed in `processEconomy()`
- Default consequences: relationship damage, stability penalty

### Final Fix: Sector Tapping
- Added missing `@State selectedSector`, `.onTapGesture`, and `.sheet(item:)` to EconomicHubView so sectors open SectorDetailView
