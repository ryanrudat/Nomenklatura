## 3. GameEngine Crash Safety Fix

### Problem
`weightedRandom` function at line 1406 called `fatalError` when passed an empty array, which would crash the app in production.

### Solution
Changed return type to optional `T?` and replaced `fatalError` with `assertionFailure` (debug-only). Updated call site to provide fallback value.

### Files Modified

#### `Services/GameEngine.swift`
```swift
// Before (line 1406):
private func weightedRandom<T>(_ items: [T], weights: [Int]) -> T {
    guard !items.isEmpty else {
        fatalError("weightedRandom called with empty items array")
    }
    ...
}

// After:
private func weightedRandom<T>(_ items: [T], weights: [Int]) -> T? {
    guard !items.isEmpty else {
        assertionFailure("weightedRandom called with empty items array")
        return nil
    }
    ...
}
```

- Updated call site at line 1306 with nil-coalescing: `weightedRandom(fates, weights: weights) ?? .retired`
