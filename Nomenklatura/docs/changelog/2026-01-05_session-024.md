# Session 024 - Bureau Integration & Affinity Feedback

**Date:** 2026-01-05

## Summary

This session focused on investigating and fixing issues with bureau integration and player feedback. The user reported that the game stopped after 20 turns and that bureau choices didn't seem to connect to gameplay. Investigation revealed the 20-turn limit is an intentional WIN condition, and the real issue was lack of visible feedback connecting player choices to bureau career paths.

## Issues Investigated

### 1. 20-Turn Game Stop (Clarified - NOT A BUG)

**Finding:** The 20-turn limit is a **Survival Victory** win condition, not a bug.

**Location:** `Services/GameEngine.swift` (lines 529-538)

When a player becomes General Secretary and survives 20 turns, they win the game with the message:
> "Twenty years of power. Your portrait hangs in every office. Your name is spoken with reverence—and fear. You have outlasted them all. History will remember you as... well, that depends on who writes it."

### 2. Bureau Integration Issues (FIXED)

**Root Cause:** Players couldn't see how their scenario choices connected to bureau access and career path progression. The archetype system was working correctly in the background, but there was no UI feedback.

**Solution:** Added visible feedback at multiple points in the game flow.

## Technical Details

### Bureau Access System (Verified Working)

The `AccessLevel` system (`Models/World/AccessLevel.swift`) properly connects bureau affinity to gameplay:

| Condition | Access Bonus |
|-----------|--------------|
| Committed track | +2 to relevant feature category |
| Related track | +1 to overlapping category |
| High affinity (25+) | +1 bonus even without commitment |

**Feature Categories Affected:**
- `.diplomatic` - Embassy, foreign relations, treaties
- `.economic` - Economic data, trade flows, budget
- `.intelligence` - Classified info, espionage, covert ops
- `.military` - Defense data, troop movements
- `.administrative` - Internal Party affairs, personnel

## User-Facing Impact

Players will now see:

1. **Before decisions:** Small gold badges on options showing which bureau they signal
2. **After decisions:** "EXPERTISE GAINED" card showing:
   - Which bureau their choice built affinity for
   - How many points they gained
   - Progress bar toward bureau access
   - How many more points needed to unlock

This creates a visible feedback loop connecting scenario choices to career progression, addressing the perception that bureau choices don't affect gameplay.

## Notes

- The 25-point threshold for bureau access remains unchanged
- Bureau access bonuses (+2 for committed track, +1 for affinity) continue to affect feature access as designed
- No changes to the underlying affinity calculation system - only UI feedback added
