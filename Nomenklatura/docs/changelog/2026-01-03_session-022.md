# Session 022 - Standing Committee Overhaul: Deduplication & Live Effects

**Date:** January 3, 2026

## Summary

This session fixed duplicate NPC proposals in the Standing Committee, massively expanded the proposal pool with immersive Communist bureaucratic scenarios, and wired up proposal-specific effects so each Standing Committee decision has unique gameplay impact.

---

## Changes Made

### 1. Fixed Duplicate NPC Proposals

**Problem:** Two or more NPCs could submit identical proposals (same title) in the same turn because `SCProposalGenerator` looped through all SC members independently with no knowledge of what others proposed.

**Solution:** Added `usedTitlesThisTurn: Set<String>` tracking in `generateProposals()`:
- Initialize with existing `pendingAgenda` titles
- Add `excludeTitles` parameter to all generator functions
- Filter proposals before `randomElement()` selection
- Insert generated title into set after each successful generation

**Files Modified:**
- `SCProposalGenerator.swift` - Added deduplication infrastructure throughout

### 3. Wired Up Proposal-Specific Effects

**Problem:** Proposals defined `effects: [String: Int]` but these were never used - all decisions applied generic category-based effects.

**Solution:** Updated `applyDecisionEffects()` in GameEngine to use custom effects when defined:

```swift
if !item.effects.isEmpty {
    // Apply custom effects from the proposal
    for (key, value) in item.effects {
        switch key {
        case "stability": game.stability += value
        case "popularSupport": game.popularSupport += value
        case "eliteLoyalty": game.eliteLoyalty += value
        case "industrialOutput": game.industrialOutput += value
        case "internationalStanding": game.internationalStanding += value
        case "militaryLoyalty": // Adjust military faction power
        }
    }
} else {
    // Fall back to category-based effects
}
```

### Design Principles Applied

1. **Feel authentic** - Use bureaucratic language, formal titles, proper procedures
2. **Have consequences** - Each decision shifts faction power, resources, relationships
3. **Create trade-offs** - No obviously "right" answer; every choice costs something
4. **Build narrative threads** - Proposals reference past decisions, foreshadow future crises
5. **Reflect NPC personalities** - Ambitious NPCs propose self-serving items, paranoid ones propose security measures
6. **React to game state** - Crisis proposals appear during crises, expansion proposals during prosperity
