# Session Changelog: 2025-12-30 Session 001

## Overview
This session implemented major narrative continuity and immersion features including document follow-up chaining, world event cascades, role-based document weighting, and a clearance-based redaction system. Also renamed the app to "The Apparatus" and fixed faction selection flow issues.

## Changes Made

### 1. Document Follow-up Chaining System

**Files Modified:**
- `Nomenklatura/Models/DeskDocument.swift`
- `Nomenklatura/Services/DocumentQueueService.swift`

**Purpose:** Documents can now spawn related follow-up documents based on player decisions, creating narrative continuity.

#### 1.1 New Tracking Fields in DeskDocument
```swift
// Document Chain Tracking (for follow-up documents)
var parentDocumentId: String?       // UUID of the document that triggered this one
var chainId: String?                // Groups related documents in the same narrative chain
var generationReason: String?       // Why this document was generated

/// Set this document as a follow-up to another document
func asFollowUpTo(documentId: String, chainId: String? = nil, reason: String? = nil) -> DeskDocumentBuilder
```

#### 1.2 Follow-up Document Generation
Implemented `generatePendingFollowUpDocuments()` in DocumentQueueService with templates for:
- **Investigation reports** - Generated after requesting investigations
- **Arrest updates** - Follow-ups to arrest authorizations
- **Appeal letters** - From characters affected by budget denials
- **Consequence reports** - Showing effects of policy implementations
- **Character reactions** - Based on character disposition after warnings
- **Policy follow-ups** - Reports on implemented policies

### 2. World Event Cascade System

**Files Modified:**
- `Nomenklatura/Models/World/WorldEvent.swift`
- `Nomenklatura/Services/WorldSimulationService.swift`
- `Nomenklatura/Services/InternationalEventService.swift`

**Purpose:** International events can trigger chains of related events with low probability (15-25%) for a stable but dynamic world.

#### 2.1 New Cascade Tracking Fields in WorldEvent
```swift
// Cascade Tracking (for event chains)
var triggeredBy: String?       // ID of parent event that caused this one
var cascadeDepth: Int = 0      // How many levels deep in the cascade chain (max 2)
var narrativeHint: String?     // Subtle text linking to parent event

var isPartOfCascade: Bool { triggeredBy != nil }
var canTriggerCascade: Bool { cascadeDepth < 2 }
```

#### 2.2 Cascade Rules (Low Probability)

| Parent Event | Possible Cascades | Probability |
|--------------|-------------------|-------------|
| borderIncident | armsBuildUp, ambassadorRecall | 15-20% |
| armsBuildUp | militaryExercise | 15-20% |
| revolution | purge, spread to neighbors | 20-25% |
| economicCrisis | tradeDispute | 15-20% |
| treatyViolation | ambassadorRecall | 20-25% |
| coup | purge | 20-25% |

#### 2.3 Authority-Gated Event Responses
Players can only respond to world events if their position/track grants sufficient authority:

| Event Type | Required Authority |
|------------|-------------------|
| Border incidents, diplomatic | Foreign Affairs track OR position level 4+ |
| Military matters | Military track OR position level 5+ |
| Political upheavals | Position level 6+ (Senior leadership) |
| Superpower confrontations | Position level 7+ (Standing Committee only) |

### 3. Role-Based Document Weighting

**File Modified:**
- `Nomenklatura/Services/DocumentQueueService.swift`

**Purpose:** Players receive more documents relevant to their career specialization.

#### Weight Multipliers by Track
| Career Track | Document Bonus |
|--------------|----------------|
| Security Services | 2x security, 1.5x crisis documents |
| Economic Planning | 1.75x economic documents |
| Military-Political | 2x military documents |
| Party Apparatus | 1.75x political, 1.5x personnel documents |
| Foreign Affairs | 2x diplomatic documents |
| State Ministry | 1.5x economic, 1.5x political documents |
| Regional | 1.5x economic, 1.5x personnel documents |

#### Clearance-Based Filtering
- Low clearance (1-2): No crisis documents
- Higher positions (5+): More personnel matters
- Very high positions (6+): More diplomatic matters

#### 4.1 RedactedTextView Component
```swift
struct RedactedTextView: View {
    let originalText: String
    let isRedacted: Bool
    var revealable: Bool = false
    var requiredLevel: Int = 0
    var style: RedactionStyle = .blackBar

    enum RedactionStyle {
        case blackBar           // Solid black bar covering text
        case blackBlocks        // Individual character blocks (████████)
        case strikethrough      // Text with heavy strikethrough
        case blur               // Blurred text (iOS 17+)
        case classified         // [REDACTED] replacement text
    }
}
```

#### 4.2 RedactionManager Utility

struct RedactionManager {

### 6. Fixed Faction Selection Flow

**File Modified:**
- `Nomenklatura/ContentView.swift`

#### 6.1 Fixed "Restart Game" Functionality
**Problem:** "Restart Game" menu option said "Start a new game with the same faction" but actually just returned to main menu.

**Solution:** Added `onRestartWithSameFaction` callback to GameView that captures current game's `campaignId` and `playerFactionId` before creating a new game with those same values.

#### 6.2 Fixed Old Save Migration
**Problem:** Users with old saves from before faction system couldn't see faction selection.

**Solution:** Added check on app launch - if any existing game lacks a `playerFactionId`, all games are deleted to force fresh start with proper faction selection.

## Technical Notes

### Design Decisions

1. **Event Cascade Probability**: Low (15-25%) for stable, impactful world rather than chaotic event spam

2. **Authority Hierarchy**: Position-gated access ensures players can only influence events appropriate to their rank

3. **Document Chaining**: Uses flag system (`pending_doc_*`) set by document options, processed on subsequent turns

4. **Redaction Styles**: Multiple visual styles available for different document types and contexts
